## Project Description

Clinic Visit Log is a Flutter application that allows students to record their visits to the school clinic by providing their symptoms or reason for consultation. It also provides a nurse dashboard where nurses can view student visit records, monitor the clinic queue, and mark visits as attended.

The system aims to make recording and monitoring clinic visits easier and more organized.

## Technologies Used

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
